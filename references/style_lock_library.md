用于填写 `[Style Lock]` 与 `[通用约束栏 · 风格声明]`。每张卡给六维指纹，
**选择时必须与 `context_pack.md` 的实测指标对得上**，不得凭喜好硬套。

## A. 导演 / 影片风格指纹卡

### A1. 大卫·芬奇式精密冷感
调色：低饱和冷青，暗部无细节的纯黑，高光克制不溢出｜光比：2–3 级，顶光/侧硬光
镜头：极稳（几乎无手持），对称或极致三分，35–50mm，f/2.8 前后分离
剪辑：镜头偏长，切换极少，切换点常落在台词之后半拍
声音：低频嗡鸣 + 精密的环境音设计，几乎无配乐或极简电子音床
材质：干净无颗粒，锐度中等偏上，皮肤保留真实纹理不美化
适用：悬疑、心理、都市冷感、科技惊悚

### A2. 王家卫式都市浪漫与时间感
调色：高饱和暖调 + 青绿阴影，霓虹倒影，色彩主观化
光比：1–2 级，混合光源（霓虹/钨丝/荧光）色温冲突
镜头：手持 + 慢门拖影，中近景为主，构图倾斜，前景常有遮挡物
剪辑：跳切、重复动作、留白停顿
声音：怀旧流行乐/爵士 + 画外音独白 + 城市环境音
材质：明显的胶片颗粒与轻微光晕，画面有湿感
适用：都市情感、回忆、暧昧、孤独

### A3. 韦斯·安德森式形式感
调色：高明度马卡龙色（粉/黄/薄荷绿/砖红），平面化，无强阴影
光比：1 级以内，均匀漫射平光
镜头：二维对称构图 + 正面机位 + 长焦压缩 + 极慢或固定
剪辑：切换精准如节拍器，常有快速横摇衔接
声音：轻快原声乐器（拨弦/木琴），旁白冷静
材质：干净，色彩分层明显，无颗粒
适用：童话、荒诞、家庭、品牌调性片

### A4. 丹尼斯·维伦纽瓦式肃穆科幻
调色：雾霾灰 + 橙黄 + 大面积单色块，暗部厚重
光比：2–3 级，逆光剪影与体积光常见
镜头：极简构图 + 巨物尺度对比 + 缓慢推近 + 固定长镜
剪辑：极慢，镜头常超过 5s，动作克制
声音：低频轰鸣 + 合成器长音 + 大段静默
材质：细腻颗粒、雾气、扬尘
适用：科幻、末世、宗教感、宿命

### A5. 张艺谋式东方色彩仪式
调色：高饱和三原色块（红/黄/青绿），单色主导整个段落
光比：2–3 级，讲究的侧逆光
镜头：对称、中远景、群体阵列、仪式化调度
剪辑：段落式，节奏庄重
声音：鼓、弦乐、群体人声
材质：绸缎/纸张/织物纹理明显，颗粒中低
适用：历史、东方美学、品牌国潮

### A6. 岩井俊二式日系清新
调色：高明度 + 低对比 + 青绿倾向 + 白场干净
光比：1 级以内，柔光/漫射窗光
镜头：固定或极缓摇，中景为主，构图上留大量天空
剪辑：缓慢，长镜多，常配钢琴
声音：蝉鸣/风铃/环境音 + 钢琴/弦乐
材质：低颗粒，柔焦，逆光光晕
适用：青春、成长、纯爱、夏日

### A7. 高端广告工业风（4A 产品片）
调色：干净白场 + 品牌色强调 + 局部高光溢出
光比：2–4 级，精准控光，硬光造型产品
镜头：微距/长焦，f/8–f/16 保证产品全清，运动控制极稳（轨道/robot）
剪辑：严格卡点，镜头 0.3–1.5s，快节奏蒙太奇
声音：定制音乐 + 精心设计的拟音（click/whoosh/riser）
材质：极高锐度、干净无颗粒、材质反射可控（金属/玻璃/哑光）
适用：商业广告、产品发布、品牌片

### A8. 赛博朋克霓虹
调色：品红 + 青绿霓虹，高对比，湿地面彩色反射
光比：3–4 级，多光源色温冲突
镜头：广角 + 低角度 + 手持穿梭
剪辑：跳切、快速
声音：合成器 + 电子鼓 + 低频轰鸣
材质：强颗粒或数字噪点、雨雾、体积光
适用：未来、游戏、科技发布会、夜店

### A9. 粗粝纪实（贾樟柯式县城现实主义）
调色：低饱和偏土黄/灰绿，无美化
光比：1–2 级，纯自然光
镜头：手持跟拍 + 长镜 + 中全景 + 环境优先构图
剪辑：松散，保留冗余日常
声音：真实环境音（车流/人声/广播），无配乐或极少量
材质：颗粒明显，锐度不高，画面"不精致"
适用：社会观察、人文、真实故事

### A10. 黑色电影（Film Noir）
调色：单色或极低饱和 + 深黑
光比：4 级以上，百叶窗条纹光/硬边阴影
镜头：低角度仰拍、倾斜构图、广角近身
剪辑：沉稳
声音：爵士萨克斯 + 画外音旁白
材质：颗粒重，烟尘/雨雾
适用：犯罪、侦探、硬汉、反转

### A11. 3D 渲染 / 动画长片质感
调色：高饱和 + 色彩分层明确，高光略"塑料"
光比：1–2 级，全局光照均匀
镜头：镜头语言自由（无物理限制），可大景深
剪辑：明快
声音：管弦乐 + 拟音化对白
材质：边缘极干净、无噪点、材质表现夸张（毛发/布料/金属）
适用：动画、儿童内容、IP 短片

### A12. 短视频信息流语汇
调色：高饱和 + 高对比 + 滤镜感强
光比：1–2 级，正面补光/环形灯
镜头：竖屏、中近景、手机手持、频繁变焦
剪辑：镜头 0.5–2s，前 3s 必出钩子，卡点率高，字幕/贴纸常驻（但若原片无字幕则写进 NOT）
声音：热门 BGM + 人声贴耳 + 音效夸张
材质：中等锐度，偶有美颜磨皮（皮肤细节被抹平）
适用：种草、口播、剧情短剧

## B. 核心张力原型库（填 `[Style Lock]` 的「核心张力是……」）

从下面挑最贴合的一到两个，改写成贴合本片的句子，不要直接抄词：

- **接触前的迟疑** — 动作已开始，意愿还在犹豫
- **亲密与距离** — 身体靠近，关系没靠近
- **观察与被观察** — 有人在看，也可能有人在被看
- **秩序与失控** — 整洁的表象下正在崩塌
- **身体的疲惫与意志** — 身体在先放弃，意志还在坚持
- **时间的不可逆** — 一个已经无法回头的瞬间
- **欲望的克制** — 想要，但选择不要
- **日常里的异样** — 一切正常，就是有一点不对
- **代际的沉默** — 想说的话卡在两代人之间
- **被规训的自由** — 环境许可范围内的微小反抗
- **工具与人的对立** — 机器精准，人笨拙
- **商品化的情感** — 真诚被包装成卖点
- **重复中的偏差** — 同一动作第一万次做出第一万零一次不同
- **消失前的最后一瞥** — 正在失去的东西被镜头留住

## C. 情绪弧线结构（用于 segment 划分与节奏判断）

短视频（≤60s）常见四拍：

| 拍 | 占比 | 功能 | 画面特征 |
|---|---|---|---|
| 钩子 | 0–15% | 制造疑问或强刺激 | 最亮/最快/最反常的镜头，常是大特写或剧烈运动 |
| 展开 | 15–55% | 交代与铺垫 | 景别舒展，运动减缓，信息量最高 |
| 转折 | 55–85% | 情绪或信息反转 | 景别突变（全→特）、色调突变、静默或爆发 |
| 收束 | 85–100% | 留白或定格 | 长镜、静止、暗部增大、声音收干或留白 |

**用法**：把实测的 `motion` 曲线、`dark_ratio` 曲线、`sparkline` 响度曲线与上表对照，
在输出开头的 segment 说明中写出「本片遵循 X 拍结构，转折点位于 tc 00:XX」。
若结构与四拍明显不符（如全程卡点无叙事），如实说明并按实际结构归纳。
