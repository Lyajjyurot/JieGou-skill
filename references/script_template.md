# 输出模板与字段规范（导演级分镜脚本）

本文件定义**每个字段的填写规范**：写什么、硬性要求、数据来源、降级写法、自检清单。
字段规范与用哪份模板无关，**必须遵守**。

---

## 一、整体结构

**模板骨架不由本仓库提供。** 输出格式由使用者自己的模板决定，取用优先级：

1. `references/output_template.md` —— 使用者自备的模板，优先使用
2. 对话中直接给出的模板内容
3. 以上都没有时，按下面的**字段序列**组装一份通用结构（会缺少使用者模板里的
   版式装饰与专有字段名，此时应明确告知使用者"当前为通用结构，
   如需与你的模板逐字一致，请把模板放到 `references/output_template.md`"）

### 层级与字段序列（通用结构）

一份脚本由 1 个或多个 **SEGMENT** 组成；每个 SEGMENT 含一个**通用约束栏**和若干**镜头块**。

**SEGMENT 头**：编号/名称 · 总时长 · 镜数 · 风格短标签 · 场景

**通用约束栏**（本 segment 内所有镜头共享）依次为：

| 序号 | 项 | 内容 |
|---|---|---|
| 1 | 风格声明 | 写实/动画/粘土/胶片 + 色调倾向 + 镜头语言 + 特效基调 |
| 2 | 通用 NOT | 禁出现元素清单 |
| 3 | 角色资产 | 出场角色的可复现选角/声音描述 |
| 4 | 道具资产 | 关键道具的位置/状态/材质 |
| 5 | 特效资产 | 特效的形态/运动/颜色；无则写「无」 |
| 6 | 背景环境 | 场景中固定不动的元素 |
| 7 | 光影风格卡 | 主光色温/强度/方向 + 氛围 + 暗部占比 + 对比度 + 四色号 |
| 8 | 音效风格卡 | 环境音 + 动作音效 + 特殊音效 + 混响 + 禁止 BGM 声明 |
| 9 | 场景空间关系 | 角色站位 + 道具分布 + 前后景 + 时间 + 天气 + 空间边界 |

**镜头块头**：镜头序号 + 标题 · 起止时间码 · 视角 · Beat 编号-名称

**镜头块字段**（固定 14 项，逐项规范见 §三）：

```
[叙述] [机位] [镜头] [构图] [运镜] [画面动态] [光影] [色号]
[材质] [声音] [对白] [本镜NOT] [Style Lock]
     （共 13 个标注字段 + 镜头块头的「视角」等构成 14 项）
```

> 若使用者模板的字段名或顺序与此不同，**以使用者模板为准**；
> 本文件的每项规范按语义对应到相应的字段即可（如模板里叫「光线」的字段，
> 就按 §三 的 `[光影]` 规范来填）。

### SEGMENT 切分规则

- 短视频（≤60s）：通常 **1 个 segment**。若中途出现明确的场地/时间/叙事段落跃迁
  （如「室内→街景→产品特写」），才切成 2–3 个 segment。
- 每个 segment 容纳 **2–8 个镜头**。超过 8 镜说明该拆段。
- segment 名称用「场景+功能」命名，如 `A-晨光卧室`、`B-产品特写`。
- `[总时长]` 是该 segment 的实际秒数区间；`[镜数]` 为镜头数量；`[风格]` 是风格短标签；
  `[场景]` 是地点/环境。

## 二、通用约束栏 · 逐项规范

| 字段 | 内容要求 | 数据来源 |
|---|---|---|
| 风格声明 | 写实/动画/粘土/胶片 + 色调倾向 + 镜头语言 + 特效基调。**一句话内给全** | 全片画像的调色板/饱和/颗粒/锐度 |
| 通用 NOT | 禁止出现元素的英文清单，`NOT a · NOT b · NOT c`。包含：画面外元素、错误风格、水印、字幕（若原片无字幕）、多余人物 | 从画面实际内容反推「不该出现什么」 |
| 角色资产 | 每个角色：外形/服装/特征/音色。群像另起一项。**必须写成可复现的选角描述**（年龄感、发型、体型、服装颜色材质、面部特征、声音年龄与音色） | 关键帧观察 + 音轨人声特征 |
| 道具资产 | 每个道具：位置/状态/材质 | 关键帧观察 |
| 特效资产 | 每个特效：形态/运动/颜色。无特效则写「无」 | 关键帧观察 |
| 背景环境 | 场景固定不动的元素：墙纸/家具/天空/地面/建筑 | 关键帧观察 |
| 【光影风格卡】 | 主光源色温/强度/方向 + 氛围 + 暗部占比 + 对比度 + 色号 dominant/accent/shadow/unique | **直接引用实测**：`kelvin` / `dark_ratio` / `contrast` / `palette` |
| 【音效风格卡】 | 环境音 bed + 动作音效 + 特殊音效 + 混响时间 + 禁止 BGM 声明 | 频段画像 + 分段判定 + LUFS |
| 【场景空间关系】 | 角色站位 + 道具分布 + 前后景关系 + 时间 + 天气 + 空间边界 | 关键帧观察（首帧确立空间） |

## 三、镜头块 · 逐字段规范

时间码格式 `0:00-0:00`（分:秒，秒保留一位小数或整数，与素材实际时长一致）。
`视角=` 取值：`旁观` / `全景` / 角色名（跟某角色的主观/贴身视角）。

| 字段 | 写什么 | 硬性要求 | 数据来源 |
|---|---|---|---|
| `[叙述]` | 整段叙述本镜内容：环境、动作、交互、情绪、镜头内事件顺序。保持段落完整 | **必须是一段完整散文**，不列点。要能让人闭眼复原这一镜 | 读 detail 接触表 + 关键帧 |
| `[机位]` | 视角 · 平视/俯角/仰角 · 高度（约离地/离桌高度） · 景别（大远景/远景/全景/中景/中近景/近景/特写/大特写） | 景别必须六选一并精确到层级 | 关键帧：人物占比、肤色占比、画面裁切位置 |
| `[镜头]` | 焦距（mm 等效）· 光圈（f 值）· 景深描述（深/浅/极浅，前后景虚化程度） | 光圈用 `fg_bg_sharpness_ratio` 校准（>3.0 → f/1.4–2.0；1.5–3.0 → f/2.0–4；0.6–1.5 → f/4–8；<0.6 → f/8–16），但该值只是弱线索，必须结合读图确认景深 | 实测 `fg_bg_sharpness_ratio` + 透视判断 |
| `[构图]` | 主体位置（九宫格）· 前后景关系 · 焦平面锁定对象 · 留白区域 | 用画面对位语言（左上/右下/中线/对角） | 关键帧 |
| `[运镜]` | 固定/推拉/摇摄/跟拍/手持/跳切 · 速度 · 幅度 · 是否防抖 | 用光流实测：`cam_move` 定速度、`cam_dx/cam_dy` 定方向、`cam_zoom` 定推拉。注意区分「镜头在动」与「主体在动」（看 `local_motion`） | 实测光流字段 |
| `[画面动态]` | 逐项列出本镜内所有可见运动：角色动作、道具位移、特效变化 | **逐项分号分隔**，每条一个可执行动作；动作幅度参考 `local_motion` | 连续关键帧 + 实测 `local_motion` |
| `[光影]` | 主光色温/强度 · 补光 · 特殊光效 · 暗部比例 · 对比度 | 数字直接取实测：色温 K、暗部占比、对比度、明暗比级数。**明暗比 `light_ratio_stops` 是画面级亮度比，不要写成布光光比**（见 analysis_rules §4） | 实测 `kelvin` `dark_ratio` `contrast` `light_ratio_stops` |
| `[色号]` | `dominant / accent / shadow / unique` 四色 hex | **必须与实测 palette 一致**，允许按语义微调 ±5 | 实测 `palette` |
| `[材质]` | 角色材质 · 道具材质 · 环境材质 · 特效材质 · 颗粒感描述 | 颗粒感取实测 `grain_sigma` 映射（见 analysis_rules） | 实测 `grain_sigma` `hf_energy` |
| `[声音]` | 环境音 · 动作音效 · 特殊音效 · 音量变化 · 静默留白 | 有实测分段/静默/响度时必须引用 | 实测 `segments` `silences` `loudness` |
| `[对白]` | 角色名（音色/语气/语速/情绪/音量）：「台词内容」或 `无` | 无可辨识语音时写 `[对白] 无（本镜为纯环境音/纯音乐）`，**不得凭空编造台词** | 实测分段判定为「疑似人声主导」才可写对白，且须标注来源 |
| `[本镜NOT]` | 本镜禁止出现的具体元素，逐项列出 | 比通用 NOT 更具体，针对本镜风险点 | 由本镜内容反推 |
| `[Style Lock]` | 本镜风格锁定：参考导演/电影/视觉风格 + 核心张力 | 一段话，`参考 ... 的 ... ，核心张力是 ...` | analysis_rules 的风格匹配表 |

## 四、无音轨 / 无对白时的降级写法

| 情况 | 写法 |
|---|---|
| 整个素材无音轨 | 通用约束栏的【音效风格卡】写「原素材无音轨；按画面节奏设计建议音效：…」；每镜 `[声音]` 写建议设计，并标注 `（建议/原片无声）` |
| 有人声但无 ASR 转写 | `[对白] 角色名（音色/语气/语速——基于波形推测）：「原片有对白，持续约 X.Xs（起止时间码），语义待补；转写建议：…」`，**不得编造具体词句** |
| 纯 BGM 无对白 | `[对白] 无（全片无对白，情绪由音乐与画面承担）` |
| 卡点剪辑明显（卡点率高） | 在 `[画面动态]` 与 segment 说明中显式写出「切换点踩在 BPM≈XXX 的拍点上（卡点率 XX%）」 |

## 五、填写示例（节选，示范颗粒度）

```
【镜头3：指尖推开抽屉】| 0:04-0:06 | 视角=林晚 | Beat 2-发现
[叙述] 林晚的右手从画面右下切入，指腹贴上深胡桃木抽屉面板，指节因发力而微微泛白。
抽屉被推开一道缝，暗处泄出一线冷白的光，落在她虎口上。她的呼吸声在这个近景里被放大，
动作停顿了半拍——像在确认自己是否真的愿意看进去。镜头始终锁在她的手与那道缝上，背景
的客厅被压成一片虚化的暖褐色。
[机位] 林晚主观侧后方 · 平视略俯 · 约与桌面同高（离地约 75cm） · 近景切特写
[镜头] 等效 50mm · f/1.8 · 极浅景深，仅指尖与抽屉缝在焦内，背景散景呈奶油状
[构图] 手位于画面右下三分交点，抽屉缝形成由右下向左上的对角线；左上大面积留白给暖褐背景
[运镜] 手持跟拍 · 缓慢 · 幅度约 5cm 微推 · 轻微呼吸感晃动，无防抖（保留手持质感）
[画面动态] 右手三指推动抽屉面板前移约 4cm；抽屉缝隙由 0 扩张至约 3cm 漏出光带；
指节泛白程度加深；背景散景随微推轻微分离
[光影] 主光 3200K 暖钨丝，来自画面左上的台灯，强度中等；补光为窗外冷调 5600K 环境光，
勾勒手背轮廓；暗部占比约 41%，对比度 0.58，光比约 3.5:1
[色号] dominant #3E2E24 / accent #C9A227 / shadow #14100D / unique #8FA9B8
[材质] 皮肤材质细腻有毛孔细节；胡桃木纹可辨，表面哑光；抽屉缝内壁为冷白塑料反光；
空气中有轻微浮尘颗粒；颗粒感 σ1.9，属轻胶片质感
[声音] 环境音为极轻的室内底噪与远处车流（约 -42dBFS）；动作音效：木质摩擦声短促
（0.3s）；对白后静默 0.4s 形成留白；音乐在中频铺底，无明显低频
[对白] 林晚（25-30 岁女声/中低音区/气息略紧/语速偏慢/克制/音量偏小）：
「……你自己看。」（起 0:04.6，止 0:05.4，波形判定为人声主导段）
[本镜NOT] NOT 多余手指 · NOT 美甲装饰 · NOT 抽屉内物件清晰可见 · NOT 背景家具细节可辨
· NOT 冷白主光（主光必须为暖钨丝）
[Style Lock] 参考《燃烧女子的肖像》式的手部特写调度与自然光逻辑，叠加东亚家庭剧的
克制美学；核心张力是「接触前的迟疑」——动作已发生，意愿仍在犹豫。
```

## 六、质量自检清单（落笔后逐项核对）

- [ ] 每个镜头的 `[色号]` 与 `context_pack.md` 的实测 palette 一致（或说明了调整理由）
- [ ] 每个镜头的 `[光影]` 引用了实测色温/暗部占比/对比度
- [ ] 每个镜头的 `[材质]` 颗粒感有 σ 数值依据
- [ ] 时间码连续、无重叠、无跳跃，总和等于素材总时长
- [ ] 至少读过每个镜头自己的 detail 接触表
- [ ] 无凭空编造的对白（未转写时必须标注「语义待补」）
- [ ] 有音轨时，`[声音]` 引用了静默区间与响度特征
- [ ] `[本镜NOT]` 每镜至少 2 项，且针对本镜具体风险
- [ ] `[Style Lock]` 给出了可识别的导演/影片参照并点明核心张力
