# 指标 → 导演术语映射规则

本文件把 `context_pack.md` 里的**实测数字**翻译成**专业术语**。写脚本时必须走这套映射，
不得凭感觉给数值。所有阈值是经验值，允许在明显不符时偏离，但偏离要能被画面证据支持。

---

## 1. 景别判定

| 依据 | 大远景 | 远景 | 全景 | 中景 | 中近景 | 近景 | 特写 | 大特写 |
|---|---|---|---|---|---|---|---|---|
| 人物在画面高度占比 | <10% | 10–25% | 25–70%（全身） | 70%（腰以上） | 胸以上 | 肩以上 | 面部占满 | 眼/嘴/手等局部 |
| 实测 `skin_ratio` 参考 | ≈0 | <0.01 | 0.01–0.04 | 0.03–0.08 | 0.06–0.14 | 0.10–0.22 | 0.15–0.35 | >0.25 |

- 无人物时按**主体物件在画面中的占比**对应到上表（产品特写 → 特写）。
- `skin_ratio` 只作辅助，**必须结合读图确认**；暖色墙面、食物也会误触发肤色检测。

## 2. 焦距与光圈推定

**光圈**（依据 `fg_bg_sharpness_ratio`，中心区拉普拉斯方差 / 四条边缘带拉普拉斯方差均值）：

| `fg_bg_sharpness_ratio` | 提示 | 推定光圈 |
|---|---|---|
| >3.0 | 中心显著锐于边缘 | f/1.4–f/2.0 |
| 1.5–3.0 | 中心略锐 | f/2.0–f/4 |
| 0.6–1.5 | 分布均匀 | f/4–f/8 |
| <0.6 | 边缘更锐 | f/8–f/16 |

> ⚠️ 这个比值只是**弱线索**：背景是平滑面（天空/纯色墙/虚化灯箱）时比值天然偏高，
> 主体偏侧时偏低。**必须结合 detail 接触表目视确认景深**，不可只凭数字写光圈。

**焦距**（读图判断透视压缩与视角宽度）：

- 面部明显变形、边缘拉伸、环境占比大 → **16–24mm 广角**
- 接近人眼自然感、室内对话常用 → **35–50mm**
- 面部扁平化、背景被压缩贴近人物 → **85–135mm 中长焦**
- 背景与人物几乎贴合、空间被压成平面 → **>200mm 长焦**

## 3. 运镜判定

本流水线用**稠密光流**（Farneback）把运动分解成三路，写脚本时按下表取用：

| 实测字段 | 物理含义 | 对应字段 |
|---|---|---|
| `cam_move` | 全局平移速度，单位「帧宽/秒」（中位光流向量） | `[运镜]` 的移动类型与速度 |
| `cam_dx` / `cam_dy` | 水平/垂直分量，定左右上下 | `[运镜]` 的方向 |
| `cam_zoom` | 散度，单位「每秒画面尺度变化率」，正=推近，负=拉远 | `[运镜]` 的推/拉 |
| `local_motion` | P90 残差光流速度 = 主体/局部动作强度 | `[画面动态]` 的动作幅度 |

**移动速度分级**（`cam_move`，帧宽/秒）：

| 区间 | 判定 | 典型手法 |
|---|---|---|
| <0.015 | 固定机位 | 三脚架固定 |
| 0.015–0.05 | 极缓移动 | 呼吸感微动、极慢微推 |
| 0.05–0.20 | 缓慢移动 | 慢摇、慢跟、稳定器缓移 |
| 0.20–0.55 | 中等速度移动 | 常规跟拍、摇移 |
| >0.55 | 快速移动 | 甩镜、高速跟拍、奔跑镜头 |

**推拉速度分级**（`cam_zoom`，/秒）：

| 区间 | 判定 |
|---|---|
| <0.01 | 无推拉 |
| 0.01–0.04 | 缓慢推/拉（电影里最常见的慢推） |
| 0.04–0.12 | 中速推/拉 |
| >0.12 | 快速推/拉（冲击变焦 / 急推） |

**主体动作分级**（`local_motion`，P90 残差流速）：

| 区间 | 判定 |
|---|---|
| <0.08 | 主体近乎静止 |
| 0.08–0.35 | 主体轻微动作 |
| 0.35–0.90 | 主体明显动作 |
| >0.90 | 主体剧烈动作 |

**组合读法**（用于区分「摄影机在动」还是「人被拍在动」）：

- `cam_move` 高 + `local_motion` 低 → **镜头在动，画面内容静止**（环境摇移、空镜推移）
- `cam_move` 低 + `local_motion` 高 → **机位固定，主体在动**（固定镜头里的表演/动作）
- 两者都高 → **跟拍**（镜头跟着运动主体同步移动，两者残差都大）
- 两者都低 → **静态构图**，张力靠光影/构图/表演细节承担

**注意**：切换点那一帧的光流是跨镜头的伪值，已在统计时剔除；若某镜 `n_flow_samples` 为 0
（镜头极短或被判定为单帧），则运镜字段需完全依赖读图判断。

## 4. 光影术语映射

**对比度** `contrast`（=p95−p5 归一）：<0.30 低对比/柔光灰调 · 0.30–0.48 中低对比 ·
0.48–0.62 中等 · 0.62–0.75 较高 · >0.75 高对比硬调。

**明暗比** `light_ratio_stops`（=log2(亮部15%均值 / 暗部15%均值)，分母下限 5/255、上限封顶 6 级）：

| 级数 | 判定 |
|---|---|
| <1 | 画面明暗接近，近纯环境光 |
| 1–2 | 常规明暗层次 |
| 2–3 | 暗部明显，主光造型感 |
| 3–4.5 | 强明暗交错，暗部占比大 |
| >4.5 | 极端对比（死黑/纯白或舞台式布光） |

> ⚠️ 这是**画面级亮度比**，不是布光光比。真正的布光光比（主光:辅光）是主体上的照度比，
> 无法从成片直接测出。写 `[光影]` 时用「画面明暗比」的措辞，或从画面判断主光方向后
> 用「主光强、辅光弱」这类定性描述，**不要声称测量了布光光比**。

**暗部占比** `dark_ratio`：<0.15 高调（通透明亮）· 0.15–0.30 中间调 · 0.30–0.45 偏暗部（电影感）· >0.45 低调（暗沉压抑）。

**色温** `kelvin`：<3200 暖黄（钨丝/烛光/篝火）· 3200–4500 暖白（日出日落）·
4500–5800 中性白（日间自然光）· 5800–7000 偏冷白（阴天/日光灯）· >7000 冷蓝（蓝调时刻/冷调布光）。

**分离调色** `split_tone` 字段：出现「青橙分离」即写进光影与色号两处，这是**辨识度最高的调色指纹**。

## 5. 调色风格命名（由 palette 四角色推）

| 特征 | 调色风格名 |
|---|---|
| shadow 偏青blue、accent 偏橙 | 青橙调（商业大片/都市张力） |
| shadow 偏绿、整体低饱和 | 毒绿调（惊悚/不安/病态） |
| dominant 与 shadow 同为低饱和近灰 | 褪色胶片（回忆/年代/克制） |
| dominant 高亮暖白、contrast <0.35 | 日系清新（通透/温柔/夏日） |
| 高饱和 + 高对比 + unique 为品红/青 | 赛博霓虹（未来/躁动） |
| 单色（`monochrome`=true）+ 高对比 | 黑白高调（形式感/沉重/纪实） |
| dominant 为土黄/褐 + shadow 近黑 | 油画褐调（古典/历史/庄重） |
| accent 为纯红且 vivid_ratio 高 | 红点调（仪式感/危险/张扬） |

## 6. 材质与质感映射

| 实测 | 术语 |
|---|---|
| `grain_sigma` <0.8 | 干净无颗粒（数码锐利/高码率） |
| 0.8–1.8 | 细微颗粒（轻胶片感） |
| 1.8–2.8 | 明显颗粒（胶片/复古质感） |
| >2.8 | 强颗粒（粗粝/高感光/风格化噪点） |
| `lap_var_norm` <60 | 整体偏软（失焦/强虚化/柔焦镜） |
| 60–250 | 中等锐度 |
| 250–900 | 清晰锐利 |
| >900 | 极高锐度/细节密集（8K/广告产品镜） |
| `hf_energy` 高 + 颗粒低 | 纹理丰富而非噪点（布料/木纹/石材/植被） |

**画面质感归类**（综合变量/锐度/景深/黑边/帧率）：

- **电影质感**：黑边或 2.39 画幅感 + 浅景深 + 中低饱和 + 有颗粒 + 光比 ≥2 级
- **广告质感**：极高锐度 + 高光溢出 + 干净无颗粒 + 产品特写多 + 卡点精确
- **纪录片质感**：深景深 + 自然光 + 手持晃动 + 低饱和 + 环境音重
- **短视频质感**：竖屏/高饱和 + 镜头短（<2s）+ 卡点率高 + 字幕贴纸
- **MV 质感**：强色彩 + 快速跳切 + 光效/漏光 + 非常规构图
- **动画/渲染质感**：边缘极干净 + 无噪点 + 色彩分层明显 + 物理略失真的高光
- **AI 生成质感线索**：手部结构异常 / 画面文字乱码 / 背景人物五官融化 /
  帧间细节闪烁跳动 / 光影方向前后矛盾 / 运动轨迹不合物理 / 超写实但细节逻辑混乱。
  **一旦判定为 AI 生成或含 AI 元素，必须在脚本中显式注明**，并把 AI 伪影写进 `[本镜NOT]`。

## 7. 情绪映射（四步判定法）

按顺序走完四步，得到情绪象限，再从下表取词。**不要跳过步骤直接给情绪。**

```
第1步 亮度基调：dark_ratio 高调/中间调/低调
第2步 色温温度：暖 / 中性 / 冷
第3步 色彩强度：sat_mean 极低/低/中/高/极高
第4步 张力：contrast + light_ratio_stops + cam_move + local_motion + 卡点率
```

| 组合特征 | 情绪关键词 |
|---|---|
| 低调 + 冷 + 低饱和 + 高对比 | 压抑 · 疏离 · 悬疑 · 危机 |
| 低调 + 冷 + 极低饱和 + 低对比 | 冷寂 · 空洞 · 失落 · 异化 |
| 低调 + 暖 + 中饱和 + 中对比 | 亲密 · 私密 · 怀旧 · 不安的温柔 |
| 高调 + 暖 + 中高饱和 + 低对比 | 温柔 · 日常 · 治愈 · 夏日 |
| 高调 + 暖 + 高饱和 + 高对比 | 热烈 · 市井 · 蓬勃 · 张扬 |
| 高调 + 中性 + 低饱和 + 低对比 | 通透 · 洁净 · 理性 · 疏冷的高级感 |
| 高调 + 冷 + 高饱和 + 高对比 | 未来 · 数字 · 躁动 · 赛博 |
| 单色 + 高对比 + 强颗粒 | 粗粝 · 沉重 · 纪实 · 命运感 |
| 青橙分离调色 + 中对比 | 都市张力 · 商业感 · 危险与欲望 |
| 毒绿调 + 中低对比 | 病态 · 不安 · 异常 |
| 快速运镜 + 高 BPM + 卡点率 >0.6 | 亢奋 · 炫技 · 冲刺 · 狂欢 |
| 近乎静止 + 长镜头 + 有静默留白 | 沉思 · 凝重 · 屏息 · 悬念 |
| 剧烈运动 + 低饱和 + 冷调 | 失控 · 逃逸 · 惊慌 |
| 高光溢出 + 低对比 + 暖 + 柔焦 | 梦幻 · 回忆 · 恍惚 · 天堂感 |

`[对白]` 的情绪需与画面情绪**对齐或刻意对位**；若对位（如画面温柔而人声紧绷），
在 `[Style Lock]` 的核心张力里点明。

## 8. 声音描述映射

| 实测 | 写法 |
|---|---|
| `integrated_lufs` > −12 | 母带压得很满，动态被削（短视频/广告常态） |
| −12 ~ −18 | 标准流媒体响度 |
| < −18 | 保留较多动态（电影/纪录片） |
| `lra_lu` <4 | 响度平稳，全程铺满无起伏 |
| `lra_lu` 4–9 | 正常动态起伏 |
| `lra_lu` >9 | 强动态（有爆发或大段静默） |
| `true_peak_dbfs` > −0.5 | 峰值贴近 0，有削波风险，听感偏硬 |
| `beats.bpm` 有值 | 写出 BPM，并把「音乐节拍」作为画面节奏的参照 |
| `cut_alignment.rate` >0.6 | 明确写出「卡点剪辑，X/Y 个切换踩在拍点上」 |
| `cut_alignment.rate` <0.25 | 写出「剪辑与音乐刻意错位，形成拖拽/滞涩感」 |
| `silences` 有值 | 在对应镜头的 `[声音]` 里写「静默 X.Xs 留白」 |
| `bands.sub+bass` 占比 >0.35 | 低频厚实（轰鸣/心跳/压迫感） |
| `bands.high+high_mid` 占比 >0.30 | 高频明亮（空气感/齿音/镲片/数码感） |
| 「疑似人声主导」段 | 可写对白存在，但**无转写时不得编造词句** |
| 「疑似音乐主导」段 | 写 BGM 存在与情绪色彩（不写具体曲名，除非能识别） |

## 9. Style Lock 匹配（用全片实测指标选参照）

按下面的指纹表选 1–2 个参照，再叠加一句核心张力：

|---|---|
| 青橙分离 + 中高对比 + 干净 + 卡点准 | 好莱坞商业片工业体系（如《碟中谍》式调度） |

| 雾霾灰橙 + 极简构图 + 巨物尺度 + 低频轰鸣 | 丹尼斯·维伦纽瓦式肃穆科幻 |
